


# Voice2Sign – Voice to Sign Language Translator

Voice2Sign is a small web application I developed as a project to explore how technology can help people communicate.

The application takes spoken or typed text and displays the corresponding sign language alphabet images one by one.

## Features

- Speech input using the browser's speech recognition.
- Text input for typing sentences.
- Displays sign language alphabet images.
- Simple and user-friendly interface.
- Animated display of sign images.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Web Speech API

## Project Structure

voice-to-sign-translator/
- app.py
- static/
  - script.js
  - style.css
  - signs/
- templates/
  - index.html

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install Flask:

   pip install flask

4. Run the application:

   python app.py

5. Open your browser and visit:

   http://127.0.0.1:5000/

## Note

Speech recognition depends on browser support and microphone permission. This project currently displays alphabet-level sign images and is a learning prototype, not a complete sign-language translation system.
